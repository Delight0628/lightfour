| 部分 | 标注量 | 音频 |

**CSV 格式**（无表头，每行 = 一个口技单音）：


## 碳配额（Carbon Quota）简介

碳配额是**碳排放权交易体系（ETS）**中的核心概念，指政府/监管机构分配给企业或行业的**温室气体排放许可额度**，通常以「吨二氧化碳当量（tCO₂e）」为单位。

**三个要点：**

| 概念 | 说明 |
|---|---|
| **总量控制** | 政府设定一定时期内的排放总量上限（cap），再按规则分配给控排企业 |
| **交易机制** | 减排成本低的企业可以出售多余配额，成本高的企业购买配额（trade），形成碳市场 |
| **履约清缴** | 企业实际排放必须 ≤ 持有配额，否则面临罚款；配额可跨期结转或抵消（CCER 等） |

**中国现状**：2021 年启动全国碳市场，初期覆盖电力行业；地方试点（北京、上海、深圳等）覆盖更多行业（钢铁、水泥、化工等）。欧盟 EU ETS 是全球最成熟的体系。

分配方式主要有**免费分配**（按历史排放法/基准法）和**有偿拍卖**两种。

## 碳配额（Carbon Allowance）简介

碳配额是**碳排放权交易体系（ETS）**的核心概念，指政府/监管机构分配给控排企业的**温室气体排放许可额度**，通常以「吨二氧化碳当量（tCO₂e）」为单位。其基本逻辑是「总量控制与交易」（Cap-and-Trade）：

**延伸概念**：CCER（核证自愿减排量）等碳信用可用于抵销部分履约义务（通常有限额，如中国为应清缴量的 5%）。
