# CODEC_LISTEN_HIHATS_12 — 试听包 true vs 75 vs 13p（16 层判决用）

## 结论占位
本卡只交「指标 + 盲听包 + 判决规则」；**人耳判决未出之前不得写通过/不通过**。
唯一判决数据 = Delight 填完 `listen_blind/JUDGMENT_SHEET.csv` 后由 `--score` 出的 SCORE_CARD。
**JUDGMENT_SHEET 维持关闭**：正式 96 wav 包（--listen-n 24、counts 12/6/6、FLOAT、含 dup 隐藏对照、`composition.json` 核过）到位前不得开；本 v1 混合包只留档，判决以正式包为准。

## 口径
- mel 唯一实现 `scripts/mel_metric.py`（md5 240f6f188c5d342d0bb82a25f107560a），frame_policy=min。
- 指标从磁盘 wav（subtype 见 summary.json）重算 = 试听同一信号（同字节）；旧 PCM_16 包与内存 float 路径差 ≤0.0585 属量化差、非实现差，旧包数值不与本卡并表。
- 75 臂 = EnCodec 24kHz/24kbps 码流取前 16 层（raw 32 层，等效 ≈12kbps）；16 vs 32 非控制变量。
- 13c 不进本判决（仅附录）；`frame_diff_max=0` 是结构性恒等，不当对齐/截断已证。
- R1 对齐臂唯一命名 `13p_align`（结论值 150.4%；对齐前 155.4%，同一臂前后一对，不构成两个臂）；试听 wav 臂名沿用 `13p`（文件名同源，仅作样本标识）；其余 `13p_*` 名一律禁止入卡，命中即打回；更细对齐粒度只准新实验名 `13p_subalign`，且必须与 `150.4%` 同表并注「不同对齐粒度、不可比」。
- `150.4%` 为 ±1 桶粒度、`±3 帧` 级别未测；只写「信息丢失为主」，不写「时域损失已排除」（77.6% 击打 shift=0，±80ms 窗分辨不了 ±38ms 抖动）。
- 中间带单列 `n_midband`（同时报 n 与 CI；CI 跨判定线 = 证据不足以判定，不得取三档任一档）；卡头标「未判定」，不进任何通过/不通过汇总、不进 §0 或结论段。

## 样本
- n=12 条（cymbal 4 / hihats 4 / click_60_200ms 4，见 composition.json），11 个 source，dur 78.0–571.5ms，split ['test', 'train', 'val']。
- **源包变更事故**：PI 点名的「12 条全 hihats 试听包」（PCM_16）在 2026-10-27 11:41 被 `codec_rate_ab` 重跑覆盖为本混合包（FLOAT32）；旧包本地已不存在，其 index.json 已由 @Eval 从会话记录回收存档（`overwritten_hihats12_index_recovered.json`），可照单重渲染。
- 覆盖缺口：hihats 仅 4 条 <5 → **只报数不判定**（红线）；hihats 全池 247 段 / 43 source。「16 层 hihats 生死」不能由 n=4 承担；判决样本已定（PI 2026-10-27 改判）＝正式 96 wav 包（--listen-n 24、counts 12/6/6、FLOAT、含 dup）hihats 池 6 条，从现包 247 段重抽；旧 12 条 hit_id 追认作废、不重渲（PCM_16 量化差会回灌 A/B）。
- **置信度：低**（n=12 混合、每池 n=4）。

## 判决规则（PI ㉝ 已确认并收窄：32 层出口删除）
- 每条候选判 `0=听不出 / 1=可辨·轻微 / 2=可辨·明显`（36 条候选 = 12×[75, 13p, dup]）；`judgment=1` 一律单列 `n_midband`（未判定，不进通过/不通过汇总）。
- **有效性门**：正对照 13p 需 ≥8/12 判 ≥1；负对照 dup 需 ≥11/12 判 0。任一不满足 → 本次判决无效（不许出结论）；dup 用 `true` 字节副本，判读率不达标整卡作废、不补样硬凑。
- **16 层判决（本混合包 12 条）**（只看 75 臂判 0 的条数）：≥8/12 → 通过，表述限于「16 层重建在 cymbal/hihats/click 三池人耳未见退化」；≤5/12 → 不通过，**扩样复判，仍不过记 v0 已知短板；32 层评估出口已删除**（32 层不在 v0/v1 路线、需 32GB 卡违反租卡冻结）；6–7/12 → 灰区 = 中间带，`n_midband` 单列、卡头「未判定」、不进汇总、扩样再判。
- **hihats 单 family（本包 n=4）只报数不判定**；hihats 判决 n=6（样本 = 正式 96 wav 包现包重抽 6 条，不走旧 12 条重渲）。规则（只看 75 臂判 0 条数）：≥5/6 → 结论限「hihats 未见退化（低置信）」；3–4/6 → 中间带（n_midband 单列、未判定）扩样 12 复判；≤2/6 → 扩样 12 条复判，仍不过记 v0 已知短板（32 层出口已删除、永不触发）。结论必须与「mel 0.8429 越 §8 0.8 线」两行并列在卡头，只写其一打回；人耳通过不解除越线登记；**禁止任何单行结论把 hihats 单独判为通过（含「已通过」「已稳」类表述，命中即打回）**。
- n=12 混合、每池 n=4，标低置信度；任何「通过」不得把 hihats 写成已稳类表述。

## 边界
- 本包 wav 为 FLOAT32（11:41 重跑产物），指标与试听同源；旧 PCM_16 包的 mel 数值与本卡不可并表（跨 codec 版本）。
- P5（同 sound_id 第二 rendition）缺项与本卡无关；本卡不做跨 source 泛化声明。
- 生成侧 mel/模型误差分账不在本卡；本卡只判 codec 16 层重建。
