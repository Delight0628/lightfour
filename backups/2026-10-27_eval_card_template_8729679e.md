## C. 通用红线（每次出卡自检）
1. 不得只报汇总均值——分 family + 样本数必须在。
2. 不得跨 codec 版本比较数字。
3. 不得用训练集重建冒充泛化；测试集必须是固定版本 + md5。
4. n<5 的分组只报数、不下结论；样本倾斜必须写进置信度说明。
5. 探针分不得写入 §0；§0 识别准确率只认人工标注集。

## D. 口径钉子（㉟-d 生效 2026-10-27；违反任一条 = 打回）

1. **16 层口径**：所有 codec 卡标「EnCodec 24kHz/24kbps 取前 16 层（raw 32，等效 ≈12kbps）」；
   16 vs 32 注明「码率加倍增益、非控制变量」；不得把前 16 层表述为 24kbps 等效（作废写法禁入卡，grep 0 命中为硬门槛）。
2. **镲类三层分写、禁跨比**（统一 estimator：逐条 per-hit 比值 −1 后取中位，单位 %，对真值；
   **每行强制四元组 `(列=…, 聚合=…, 池=定义+过滤式, n=…)`，缺一格的行走不进卡、走不进结论句**（PI 81））：
   - raw 逐条 min-arm（**provisional，双签后转正**）：`(列=mel*_vs_true, 聚合=median, 池=is_click_60_200==1
     时长桶跨 12 family / sound_family=hihats / sound_family=cymbal, n=3100/247/38)`：
     click `176.2%` / hihats `145.6%` / cymbal `100.6%`（PI 79 冻结数；列族已标）。
   - **原「gm 逐条 min-arm」与「组级固定臂」两行整表作废**（PI 81：该表混列 + 错标——逐条行与组级行不在同一列族、
     「gm」标签与实际聚合不符、组级 13c 读数三种变体均不可复现）；其非 `mel*_vs_true` 列产物降为
     **「跨列参考、禁引」**：不进数字栏、不进结论句、不并排（故本模板不复述其数值）。
   - **回填路径**：@Codec 用 `per_hit.csv 235158c7` 重出 mel 列三层 + 13c/13p 双臂 CI → @Eval 同表独立复算、
     逐行同值**双签** → 才从 provisional 转正；非 mel 列产物的 CI 一律不许沿用。
   - **镲类是否跨 100%：新表双签前两个方向都禁写**（PI 81 冻结；不写「只在某臂成立」，也不写「两行均超线」）；
     CI 跨判定线写「证据不足以判定」。
   - 组级臂历史误标签见 agent.md `㊿` 更正：组级两个设计臂必须**并列**呈现（有 CI / 无 CI 分标），禁用任何臂比较
     形容词，换方向用同一句式一样打回（PI 80）。
   禁用字样（grep 0 命中为硬门槛）：agent.md ㉛ / §14.14 / §14.24 点名的作废字符串——含一个口径误判的跨重建
   增量读数（它是两臂重建互相之间的 mel 距离增量，不是对真值退化率）与组级臂历史误标签；
   具体字面量不在此复述、以 agent.md 为准。
3. **15/16 项先验可用性**：验收卡禁只报「16 项 loss 全降」，必须附 `lora_targets` + `trainable_params_ratio`
   +「哪几项近似从零」对照。参考（@Talker M4）：total 3.3246B；30 张换码本表 + codec_head = 0.06606B（1.987%）；
   15 个 lm_head + 15 张嵌入表标「名义有先验、语义失配」（预训练 Qwen3-TTS 2048 码本 vs v0 EnCodec 1024）。
4. **臂命名（单一命名）**：R1 对齐臂唯一命名 **`13p_align`**，结论值 `150.4%`（对齐后；对齐前读数 155.4%，
   同一臂前后一对，不构成两个臂）；试听包 wav 的臂名沿用 `13p`（与文件名同源，仅作样本标识，不承载 R1 结论）。
   其余 `13p_*` 臂名一律禁止入卡（历史误名不复述），grep 命中即打回；更细对齐粒度只准新实验名 `13p_subalign`，
   且必须与 `150.4%` 同表并注「不同对齐粒度、不可比」。
   **`150.4%` 为 ±1 桶粒度、`±3 帧` 级别未测**；只写「信息丢失为主」，不写「时域损失已排除」
   （77.6% 击打 shift=0，±80ms 窗分辨不了 ±38ms 抖动）。
5. **中间带单列 `n_midband`**：同时报 n 与 CI；CI 跨判定线 = 「证据不足以判定」，不得取三档任一档；
   卡头标「未判定」，不得进任何通过/不通过汇总、不得进 §0 或结论段。R1 已有观测 `150.4% > 100%` 落
   「退化成立」侧，不得因中间带未定义被降级成中间带。
6. **hihats 判决（㉝ + PI 2026-10-27 收窄 + 裁决 61/62）**：
   - 出口只有「扩样复判 / 仍不过记 v0 已知短板」；**32 层评估出口已删除、永不触发**（32 层不在 v0/v1 路线，
     且需 32GB 卡、违反租卡冻结）。
   - 判决样本来源 = **正式 96 wav 包**（`--listen-n 24`、counts 12/6/6、FLOAT、含 dup 隐藏对照、
     `composition.json` 核过）里的 hihats 池 **6 条**（现包 hihats 全池 247 段重抽）；**不走旧 12 条重渲**
     （PCM_16 量化差会回灌 A/B）。
   - n=6 规则（只看 hihats 75 臂判 0 条数）：≥5/6 → 结论限「hihats 未见退化（低置信）」；3–4/6 → 中间带
     （`n_midband` 单列、未判定）扩样 12 复判；≤2/6 → 扩样 12 条复判。
   - 扩样 12 条（同池同四臂、**只准一次**，PI 62②）：≥10/12 → 只准写「hihats 未见退化（低置信）」；
     7–9/12 → 结案「证据不足以判定」+ 记 v0 已知短板，**不再扩样**；≤6/12 → 记「hihats 退化，n=12」。
   - **dup 负对照满额零容错（PI 61①）**：当轮全部隐藏 dup 必须全判 0（n=6 → 6/6、n=12 → 12/12、
     正式包 24 击 → 24/24）；差 1 条整卡作废、不补样不扩样；dup 判 1/2 → 当轮全部听感结论作废、
     卡面只写「仪器失效」。dup 仅仪器自检，**不得**当任何臂的统计证据（禁写「通过 dup 检验故 75 臂可接受」）。
     正对照 13p 判 ≥1：n=12 维持 ≥8/12；n=6 阶段只报数不设门（PI 61/62 未给数字，Eval 不自创门槛）。
   - **分族只报数（PI 62③）**：cymbal / click 不设通过线、不标置信档，只报「判 0/1/2 计数 + 样本量 +
     三档明细」；`cymbal ≥10/12 判 0` 只进「观察记录」栏；总判决 = **hihats 门 + dup 门**，
     其余族进失败案例清单。
   - **卡头两行并列铁律**：人耳结论行 + 「hihats mel 0.8429 > 0.8 Gate 越线（provisional）」行必须同时在，
     只写其一打回；人耳通过不解除越线登记。
   - **登记值 / 包内描述值分列（禁混用）**：登记值固定 **0.8429**（R4 hihats 全池 247 段中位，铁律字面量）；
     任何重抽包的描述中位（如正式包 hihats 6 条 = 0.8038）只准进「本包描述值」栏并注明样本口径，
     两者不并排、不互相替换。
   - **样本性质行（PI 裁决 78）**：判决包 picks 跨 split 混采，卡头必须写「听感样本，跨 split 混采，非泛化证据」。
   - **禁止任何单行结论把 hihats 单独判为通过（含「已通过」「已稳」类表述，命中即打回）**。
   - `JUDGMENT_SHEET` 在正式 96 wav 包 `composition.json` 核过前**不得开**；核过后判决唯一入口 = 正式包盲包
     （24 击 × REF + 75/13p/dup），v1 混合包与历史包只留档不判决。
7. **报数区（不参与 verdict）栏位（PI 62③ + 74/75）**：cymbal / click 只报 `判0 n / 判1 n / 判2 n` + 样本量 +
   三档明细（+ Wilson 95% CI）；不设通过线、不标置信档；`cymbal ≥10/12 判 0` 只进「观察记录」栏；
   **栏位禁空栏**——未测/未判必须写状态词（如「未判（判决人未填）」），不许出现空格子（空栏会被读成待办）。
   总 verdict 只由 hihats 门 + dup 门决定；其余族进失败案例清单。
