## C. 通用红线（每次出卡自检）
1. 不得只报汇总均值——分 family + 样本数必须在。
2. 不得跨 codec 版本比较数字。
3. 不得用训练集重建冒充泛化；测试集必须是固定版本 + md5。
4. n<5 的分组只报数、不下结论；样本倾斜必须写进置信度说明。
5. 探针分不得写入 §0；§0 识别准确率只认人工标注集。

## D. 口径钉子（㉟-d 生效 2026-10-27；违反任一条 = 打回）

1. **16 层口径**：所有 codec 卡标「EnCodec 24kHz/24kbps 取前 16 层（raw 32，等效 ≈12kbps）」；
   16 vs 32 注明「码率加倍增益、非控制变量」；不得把前 16 层表述为 24kbps 等效（作废写法禁入卡，grep 0 命中为硬门槛）。
2. **镲类三层分写、禁跨比**（同一 estimator：逐条 per-hit 比值 −1 后取中位，单位 %，对真值；三层各印列公式与单位）：
   - raw 逐条 min-arm：click `176.2%` / hihats `145.6%` / cymbal `100.6%`；
   - gm 逐条 min-arm：click `137.1%` / hihats `108.4%` / cymbal `98.3%`；
   - 组级固定臂（cymbal）：raw 13c `102.4%` / 13p `149.9%`；gm 13c `101.6%`（无 CI，CI 挂账纯算不阻塞）
     / 13p `120.4% [107.5,139.0]`（唯一有 CI 的臂）。
   禁用字样（grep 0 命中为硬门槛）：agent.md ㉛ 与 §14.14 点名的四个作废字符串——含一个口径误判的跨重建
   增量读数（它是两臂重建互相之间的 mel 距离增量，不是对真值退化率）与组级臂历史误标签（组级更优臂是
   13c `101.6%`，`120.4%` 是 13p 臂）；具体字面量不在此复述、以 agent.md 为准；
   「镲类跨 100%」只在 13p 组级臂成立、不构成结论，禁写入任何结论段；CI 跨 100% 写「证据不足以判定」。
3. **15/16 项先验可用性**：验收卡禁只报「16 项 loss 全降」，必须附 `lora_targets` + `trainable_params_ratio`
   +「哪几项近似从零」对照。参考（@Talker M4）：total 3.3246B；30 张换码本表 + codec_head = 0.06606B（1.987%）；
   15 个 lm_head + 15 张嵌入表标「名义有先验、语义失配」（预训练 Qwen3-TTS 2048 码本 vs v0 EnCodec 1024）。
4. **臂命名（单一命名）**：R1 对齐臂唯一命名 **`13p_align`**，结论值 `150.4%`（对齐后；对齐前读数 155.4%，
   同一臂前后一对，不构成两个臂）；试听包 wav 的臂名沿用 `13p`（与文件名同源，仅作样本标识，不承载 R1 结论）。
   其余 `13p_*` 臂名一律禁止入卡（历史误名不复述），grep 命中即打回；更细对齐粒度只准新实验名 `13p_subalign`，
   且必须与 `150.4%` 同表并注「不同对齐粒度、不可比」。
   **`150.4%` 为 ±1 桶粒度、`±3 帧` 级别未测**；只写「信息丢失为主」，不写「时域损失已排除」
   （77.6% 击打 shift=0，±80ms 窗分辨不了 ±38ms 抖动）。
5. **中间带单列 `n_midband`**：同时报 n 与 CI；CI 跨判定线 = 「证据不足以判定」，不得取三档任一档；
   卡头标「未判定」，不得进任何通过/不通过汇总、不得进 §0 或结论段。R1 已有观测 `150.4% > 100%` 落
   「退化成立」侧，不得因中间带未定义被降级成中间带。
6. **hihats 判决（㉝ + PI 2026-10-27 收窄）**：
   - 出口只有「扩样复判 / 仍不过记 v0 已知短板」；**32 层评估出口已删除、永不触发**（32 层不在 v0/v1 路线，
     且需 32GB 卡、违反租卡冻结）。
   - 判决样本来源 = **正式 96 wav 包**（`--listen-n 24`、counts 12/6/6、FLOAT、含 dup 隐藏对照、
     `composition.json` 核过）里的 hihats 池 **6 条**（现包 hihats 全池 247 段重抽）；**不走旧 12 条重渲**
     （PCM_16 量化差会回灌 A/B）。
   - n=6 规则（只看 75 臂判 0 条数）：≥5/6 → 结论限「hihats 未见退化（低置信）」；3–4/6 → 中间带
     （`n_midband` 单列、未判定）扩样 12 复判；≤2/6 → 扩样 12 条复判，仍不过 → 记 v0 已知短板。
   - **卡头两行并列铁律**：人耳结论行 + 「hihats mel 0.8429 > 0.8 Gate 越线（provisional）」行必须同时在，
     只写其一打回；人耳通过不解除越线登记。
   - **禁止任何单行结论把 hihats 单独判为通过（含「已通过」「已稳」类表述，命中即打回）**。
   - `JUDGMENT_SHEET` 在正式 96 wav 包到位前**不得开**；v1 混合包只留档不判决。
