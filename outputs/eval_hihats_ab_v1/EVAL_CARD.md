## 口径
- mel 唯一实现 `scripts/mel_metric.py`（md5 240f6f188c5d342d0bb82a25f107560a），frame_policy=min。
- 指标从磁盘 wav（subtype 见 summary.json）重算 = 试听同一信号（同字节）；旧 PCM_16 包与内存 float 路径差 ≤0.0585 属量化差、非实现差，旧包数值不与本卡并表。
- 75 臂 = EnCodec 24kHz/24kbps 码流取前 16 层（raw 32 层，等效 ≈12kbps）；16 vs 32 非控制变量。
- 13c 不进本判决（仅附录）；`frame_diff_max=0` 是结构性恒等，不当对齐/截断已证。
- R1 对齐臂唯一命名 `13p_align`（结论值 150.4%；对齐前 155.4%，同一臂前后一对，不构成两个臂）；试听 wav 臂名沿用 `13p`（文件名同源，仅作样本标识）；其余 `13p_*` 名一律禁止入卡，命中即打回；更细对齐粒度只准新实验名 `13p_subalign`，且必须与 `150.4%` 同表并注「不同对齐粒度、不可比」。
- `150.4%` 为 ±1 桶粒度、`±3 帧` 级别未测；只写「信息丢失为主」，不写「时域损失已排除」（77.6% 击打 shift=0，±80ms 窗分辨不了 ±38ms 抖动）。
- 中间带单列 `n_midband`（同时报 n 与 CI；CI 跨判定线 = 证据不足以判定，不得取三档任一档）；卡头标「未判定」，不进任何通过/不通过汇总、不进 §0 或结论段。

## 判决规则（PI ㉝ + 裁决 61/62：32 层出口删除）
- 每条候选判 `0=听不出 / 1=可辨·轻微 / 2=可辨·明显`（v1 留档包 36 条 = 12×[75, 13p, dup]；**正式判决 72 条 = 24×[75, 13p, dup]**，见 `listen_blind_v2/JUDGMENT_SHEET.csv`）；`judgment=1` 一律单列 `n_midband`（未判定，不进通过/不通过汇总）。
- **有效性门（PI 61/62 改判）**：负对照 dup（`true` 字节副本）**满额零容错**——当轮全部隐藏 dup 必须全判 0（n=6 → 6/6、n=12 → 12/12、正式包 24 击 → 24/24），差 1 条整卡作废、不补样不扩样；dup 判 1/2 → 当轮全部听感结论作废，卡面只写「仪器失效」。dup 只是仪器自检，**不得**当任何臂的统计证据（禁写「通过 dup 检验故 75 臂可接受」）。正对照 13p 判 ≥1：n=12 维持 ≥8/12；n=6 阶段只报数不设门（PI 61/62 未给 n=6 正对照数字，Eval 不自创）。
- **旧「16 层判决（本混合包 12 条）」阈值（≥8/12 / ≤5/12 / 6–7/12）作废**（PI 62③：分族只报数、总判决 = hihats 门 + dup 门）；本 v1 混合包只留档、永不判决。
- **hihats 单 family（本包 n=4）只报数不判定**；hihats 判决 n=6（样本 = 正式 96 wav 包现包重抽 6 条，不走旧 12 条重渲）。规则（只看 hihats 75 臂判 0 条数）：≥5/6 → 结论限「hihats 未见退化（低置信）」；3–4/6 → 中间带（n_midband 单列、未判定）扩样 12 复判；≤2/6 → 扩样 12 条复判。**扩样 12 条同池同四臂、只准一次（PI 62②）**：≥10/12 → 只准写「hihats 未见退化（低置信）」；7–9/12 → 结案「证据不足以判定」+ 记 v0 已知短板，**不再扩样**；≤6/12 → 记「hihats 退化，n=12」。（32 层出口已删除、永不触发）。结论必须与「mel 0.8429 越 §8 0.8 线」两行并列在卡头，只写其一打回；人耳通过不解除越线登记；**禁止任何单行结论把 hihats 单独判为通过（含「已通过」「已稳」类表述，命中即打回）**。
- **分族只报数（PI 62③）**：cymbal / click 只报「判 0/1/2 计数 + 样本量 + 三档明细」，不设通过线、不标置信档；`cymbal ≥10/12 判 0` 只进「观察记录」栏。总判决 = hihats 门 + dup 门，其余族进失败案例清单。
- n=12 混合、每池 n=4，标低置信度；任何「通过」不得把 hihats 写成已稳类表述。
