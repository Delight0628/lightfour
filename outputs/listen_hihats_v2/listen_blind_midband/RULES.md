# RULES — hihats 扩样/复判盲包（listen_blind_midband）

- 包身份：`listen_hihats_v2` 池内重抽的 **midband 专用包**（裁决 94：`usage=listen_midband_only`）。
  只在正式 96 包 hihats n=6 落 **3–4/6 或 ≤2/6** 时启用，**只准一次**。判决人：**Delight**。
- 结构：**24 组 A/B**，每组 = `*_ref.wav` + `*_cand.wav`。其中 12 组 cand 为真实重建臂，12 组 cand 为 ref 的**逐字节副本**（dup 负对照）；item 顺序随机、臂归属隐藏。
- 判读：每组填 `judgment`：**0** = 听不出退化 / **1** = 灰区 / **2** = 明确退化。
  **24/24 必填**；缺 1 行 `--score` 拒跑，不补值、不插值。
- 门槛（现行 PI 61/62/91，非旧口径）：
  - **dup 负对照满额零容错**：12 组必须 **12/12 判 0**。差 1 条 → 整卡作废、不补样、不扩样，卡面只写「仪器失效」，不得当任何臂统计证据。
  - **真实臂 n=12 三档**：判 0 **≥10/12** → 只准写「hihats 未见退化（n=12，限幅）」；**7–9/12** → 「证据不足以判定」+ 记 v0 已知短板，不再扩样；**≤6/12** → 「hihats 退化，n=12」。
  - 灰区判 1 计数 `n_midband` **单列**，不进汇总。
- **卡头两行并列铁律**：`hihats mel 0.8429 > 0.8 Gate 越线`（登记值，R4 全池 n=247）与人耳结果必须同时在卡头，只写其一打回；人耳通过**不解除**越线登记，也**不许单独写「hihats 通过」**。
- **结论限幅（裁决 104–108 之③）**：结论句只准写「hihats（本池记法构成）人耳未见退化/退化（n=12）」，本池构成 = **F 9 / Tch 2 / Tss 1**；**禁外推成「hihats family 未见退化」**。本包为听感样本、跨 split 混采（train 10/val 1/test 1），**非泛化证据**、禁入识别 test、禁作生成泛化证据。
- **盲性（裁决 108）**：判决完成前，禁向任何人透露任何 item 的臂归属、排序种子、单项 mel 值；`BLIND_KEY.json` 不随包发；`--score` 只吃 sheet，禁自动补值。
- **mel 口径**：本包不含 mel 数字。判决后 mel 一律引用冻结 `per_hit.csv`（md5 `235158c7…`）**不重算**（防会话漂移）；越线登记值唯一可写字面量 = **0.8429**。
- **凭证**：`INDEX.json` 逐文件 sha1 为唯一复现凭证；pack 级 sha256 不作凭证。
